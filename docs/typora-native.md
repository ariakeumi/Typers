# Typora 原生界面对齐

本轮以本机 Typora 的 **Github 主题、18px 正文**为对照，沿用 Rust + GPUI 的原生块编辑器。没有新增 WebView、WebKit、Electron 或浏览器编辑层。

## 已接通的界面和交互

- 白色纸面、Open Sans 字体、标题层级、引用线、列表间距和代码底色；正文最多 800px，页边距 30px。字体随二进制内嵌，许可证见 `assets/fonts/OFL.txt`。
- macOS 原生窗口按钮、居中文件名，以及文件、编辑、段落、格式、显示、主题、窗口、帮助菜单。
- 偏好设置采用 Typora 风格的浅灰图标侧栏、左对齐分组和紧凑表单；支持中英文设置搜索、快捷键筛选、浮层下拉菜单及固定的保存／取消区，深浅主题均可使用。
- 文档列表、文件树、大纲和当前标题定位；原生文件夹选择、文档摘要、文件切换及可拖动的侧栏分隔线。
- 查找、替换、全部替换、区分大小写、全词匹配、正则表达式、捕获组替换，以及当前匹配和其他匹配的高亮。
- 专注模式、打字机模式、只读模式和每个窗口独立的缩放。只读模式同时保护普通输入、IME 组合输入、源码、表格和结构编辑。
- 渲染／源码切换保留文档和选区；替换和段落格式变更进入同一套文档撤销历史。查找／替换框有独立的编辑和撤销历史。
- 底部侧栏／源码按钮和字数入口；字数窗口显示纯文本字数、字符、段落、行数和阅读时长，统计结果按文档内容缓存。
- 表格、公式、Mermaid、图片、引用、任务列表、代码高亮等继续使用原有 Rust 解析和 GPUI 渲染路径。
- 表格和图片按侧栏展开后的实际正文列宽布局，缩放及侧栏拖动会同步更新宽度预算。
- 光标位于 H3、H4、H5 标题时，行首左侧显示对应级别标签；移开光标后隐藏，不改变正文位置和保存内容。

## macOS 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 查找 | ⌘F |
| 替换 | ⌘⌥F |
| 下一个／上一个匹配 | ⌘G / ⇧⌘G；查找框中也可用 Return / ⇧Return |
| 渲染／源码 | ⌘/ |
| 显示／隐藏侧栏 | ⇧⌘L |
| 打开文件夹 | ⇧⌘O |
| 专注模式 | ⇧⌘1 |
| 打字机模式 | ⇧⌘2 |
| 只读模式 | ⇧⌘R |
| 标题 1–6 | ⌘1–⌘6 |
| 正文 | ⌥⌘0 |
| 代码块 | ⌥⌘C 或 ⇧⌘K |
| 引用／任务列表 | ⇧⌘Q / ⇧⌘X |
| 放大／缩小／实际大小 | ⌘= / ⌘- / ⌘0 |
| 最小化／全屏 | ⌘M / ⌃⌘F |

渲染／源码快捷键可在“偏好设置 → 快捷键 → 切换源码模式”中录制或重置，默认是 ⌘/。

## 运行和对照

```sh
cargo run -- assets/showcase/typora-native.md
```

可用 `VELOTYPE_CONFIG_DIR=/absolute/path/to/profile` 启动独立配置，避免已有的字体或主题偏好覆盖新默认值。主题 ID 继续兼容既有配置：`velotype-light` 显示为 Github，`velotype` 显示为 Night。

## 实现边界

这是一套原生实现，编辑模型仍是块树和 Markdown 源映射。Typora 的系统标签页、拼写检查／系统写作工具及 Pandoc 导出格式尚未完整复刻。现有 PDF 导出仍沿用项目原来的外部 Chromium 打印路径，该路径不参与编辑窗口的渲染。

对照文档为 `assets/showcase/typora-native.md`。回归覆盖原有 Markdown、选区、撤销、表格、IME、导出测试，以及新加的原生查找焦点、Unicode 高亮、正则捕获组替换、输入框撤销隔离、只读输入保护、模式切换和文件夹／侧栏边界测试。
