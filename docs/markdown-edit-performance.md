# Markdown 编辑性能排查

2026-10-25，本机 macOS arm64。输入样本为用户提供的 `markdown-test.md`：11,971 字节、650 行。GUI 操作使用临时副本，原始文件未修改。

## 原因与修复

1. 光标使用 33 ms 定时器连续淡入淡出。GPUI 中父编辑器读取了块状态，光标通知会连带执行父视图渲染，包括全篇源码映射、序列化和统计缓存检查。改为半秒显示／隐藏，仅在可编辑块所属窗口激活时运行；输入和移动仍会重置光标相位。
2. 每次 `Changed` 都重建共享引用，再无条件通知全部块和表格单元格。现在内容未变时保留 image/link/footnote 的 `Arc`，上下文相同时跳过运行时刷新及通知。真正修改定义时仍立即更新依赖块。
3. `serialize_markdown()` 原来通过 `markdown_offset_map()` 取文本，生成后丢弃两个逐字节映射数组。增加只生成文本的路径，与选区映射共用分隔符、转义和代码逻辑；普通无格式片段跳过分隔符动态规划。源码映射构造也改为使用文本序列化结果，避免额外生成内联偏移表。

## 验证结果

同一调试构建配置、同一样本：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 60 次输入，每次处理事件并重绘 | 1,636 ms | 824 ms |
| 60 次强制重绘，内容不变 | 431 ms | 288 ms |
| 原生窗口空闲 CPU，8 秒累计进程 CPU 时间采样 | 33.23% | 0.12% |

编辑耗时约减少 50%。GUI 空闲采样受窗口激活状态影响：优化版失焦后暂停光标任务，采样中未见编辑器渲染调用；前台激活时按半秒边界刷新。CPU 数值不代表持续输入时的占用。GPUI 性能测试走真实输入、事件和绘制路径，未模拟 Markdown 算法；计时用于本机前后对照，不作为 CI 阈值。

- `cargo test`：844 通过、0 失败、2 忽略（包含手动性能测试）。
- 新增回归覆盖文本／映射序列化的一致性、普通编辑不通知兄弟块、引用定义变化后的链接／图片更新、光标相位及移动重置。
- `cargo fmt --check`、`git diff --check` 通过。
- Debug 和 Release 均构建成功。`dist/Typers.app` 与本地 ZIP 已更新，并通过 ad-hoc 签名校验。

## 复测

```sh
TYPERS_PERF_MARKDOWN=/absolute/path/to/markdown-test.md \
  cargo test markdown_edit_performance -- --ignored --nocapture
```

不设置环境变量时使用仓库的 `test.md`。测试只修改内存中的文档，不保存输入文件。CPU 采样和构建日志保留于 `/tmp/typers-performance/`；这不是跨机器的性能保证。

## 滚动性能追加优化

针对同一文件继续检查滚动路径，发现每个滚动帧仍会构建全篇选区映射、为统计序列化文档，并先构造所有行的 UI 再丢弃视口外部分。本轮改动：

- 文档缓存比较实际的块内容、类型、表格、原始源码、树关系和单元格实体身份。内容未变时复用规范 Markdown；内容或映射输入变化时刷新版本。它不依赖文档是否已经处于 dirty 状态。
- 光标源码快照借用当前版本的选区映射，滚动不会重新生成或复制逐字节映射数组。光标移动仍实时读取选区，表格运行时重建和相同文本的文档替换也会使缓存失效。
- 先按轻量元数据确定行分组和挂载窗口，再为可见行、预渲染缓冲区及焦点所在行构建元素。保留原有 800 px 预渲染范围、分组间距与滚动高度估算。

相同 Debug 配置、同一文档、同一轨迹：每帧移动 120 px，120 帧向下、120 帧向上，连续跑三遍。

| 240 帧总耗时 | 本轮优化前 | 本轮优化后 |
| --- | ---: | ---: |
| 第一遍 | 2,432 ms | 1,485 ms |
| 第二遍 | 2,070 ms | 1,295 ms |
| 第三遍 | 2,017 ms | 1,309 ms |

总耗时减少约 35%–39%；三遍挂载行数分别都是 10,766／10,765／10,765。这里测量真实布局和绘制路径的总耗时，不是系统活动监视器的 CPU 百分比。输入基准也进一步降到 60 次编辑约 424 ms、60 次不变内容重绘约 127 ms。

`cargo test`：846 通过、0 失败、3 忽略。新增测试确认纯滚动复用映射、移动光标仍更新源码偏移、文本／表格修改以及运行时／文档替换后刷新缓存。原有滚动窗口、焦点行、引用分组、Unicode 选区、撤销和源码模式测试均通过。

```sh
TYPERS_PERF_MARKDOWN=/absolute/path/to/markdown-test.md \
  cargo test markdown_scroll_performance -- --ignored --nocapture
```

本轮采样、基准和构建日志保留于 `/tmp/typers-scroll-performance/`。
