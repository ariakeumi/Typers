## 发现及修复

### P1：表格、分隔线后退格会丢掉整段正文

在第 10.2 节标题行首按 Home、Backspace（标题转正文）、Backspace（跨块合并），标题文字消失。点击其他可编辑文字后保存，磁盘文件也不再包含第 10.2 节文字。安装版原生窗口稳定复现；没有发生崩溃。

原逻辑把正文追加进上一个块的 `title`，随后移除正文块。表格和分隔线序列化忽略 `title`，因此文字丢失；公式、图表等也会把正文误当自身源码。现在这些块边界上的退格只移动光标，保留两边内容。表格进入最后一个单元格，删除表格后的空段落也使用同一焦点规则。

证据：[修复前截图](qa/markdown-2026-10-27/table-boundary-before.png)。修复后的独立测试版原生窗口确认第 10.2 节文字仍存在，光标进入上方表格最后一格。

### P1：引用里的正文在重做、重新解析后改变所属结构

在第 8.4 节引用内，列表后或代码块后的空段落输入文字，再撤销、重做。列表后的新段落会被当成列表续行，围栏被转义；代码块后的新段落与后续正文合成多行后，后续行会失去引用前缀。

修复两处序列化：列表后的独立非空正文补必要的空行；引用和提示框逐个物理行添加引用前缀。源码选区映射同步计算新增空行。

### P2：全选删除、撤销后替换全文会留下文尾字符

原整份文件全选删除后残留 `。\*`。嵌套代码块的映射漏算开、闭围栏的缩进，使后续源码偏移少四字节。修复围栏缩进映射后，进一步测试“全删 → 撤销 → 输入替换全文”仍会残留字符：恢复选区时聚焦末段展开格式符号，旧显示偏移失效。

现在先建立焦点投影再恢复跨段选区，并把完整块边界映射到当前显示边界。整份文件测试覆盖删除、撤销、全文替换与再次撤销。

### P2：上下标加入中文、emoji 后重做丢格式

在第 15.1 节的 `X^2^` 中输入中文和 emoji，序列化仍使用只接受 ASCII 内容的 Markdown 上标写法，重新解析后变成普通字符。上下标的 Markdown 写法现在同时检查正文，必要时使用 `<sup>` / `<sub>` 保留格式。

### P2：缩写示例附近连续输入发生光标回跳和乱序

第 18.2 节含不配对的格式标记和缩写定义；连续输入 `QA中文😀`，原来会分散插进 `Style Sheets` 中间。新增最小复现确认每一步输入的光标位置。

引用链接重新绑定和源码空间编辑原来使用重新序列化后的偏移映射，还原的是另一份经过转义、格式规范化的源码坐标。现在使用本次实际输入的解析映射恢复光标和组合输入范围。
