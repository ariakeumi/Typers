## 扩展语法支持差异

这些语法不统一属于 CommonMark / GFM 必选能力，单列为兼容性边界，不与基础语法缺陷混算：

- `==高亮==` 原样显示；测试文件将其标为 GFM 扩展，不能据此要求所有 GFM 解析器都支持。
- `<mark>`、`<small>`、`<abbr>` 原样显示；`<u>` 可渲染，源码中的 `~2~` / `^2^` 可显示为下标／上标。
- `:smile:` 等表情短码未转换；直接 Unicode emoji 显示正常。
- 定义列表保留 `:`，未形成定义列表样式；正文可编辑保存。
- 缩写定义没有形成缩写效果，且本文件的缩写段本身已含重复、转义及不配对的星号，无法独立证明合法缩写语法的支持情况。
- 围栏 info string 的语言高亮生效，行号、指定行高亮及标题等附加元信息未显示。
- 裸 URL 未自动变成链接；尖括号 URL 和邮箱可显示为链接。
- HTML 注释在编辑器中有可编辑的提示展示。编辑器显示注释不直接视为渲染缺陷，本轮未验证导出结果。
